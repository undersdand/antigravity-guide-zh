# 项目协作规范（AGENTS.md 模板）

> 将本文件放置于项目根目录（或特定子目录），Antigravity 会自动发现并严格遵守。注意：保持精简（单文件建议远小于 24 KB），长篇教程请放入 `.agents/skills/`。

## 1. 技术栈与项目结构
- **语言 / 框架**：（例如：TypeScript + Next.js 15 / Python 3.11 + FastAPI）
- **包管理器**：（例如：严格使用 `pnpm` / `uv`，禁止混用 `npm` 或直接修改锁文件）
- **核心目录**：
  - `src/`：核心业务逻辑
  - `tests/`：单元测试与集成测试

## 2. 编码与输出约定
- 使用简体中文回复与撰写注释；代码标识符与提交信息遵循英文规范（Conventional Commits）。
- 禁止删除与当前需求无关的已有注释和文档字符串。
- 所有新增功能或修复 Bug 必须附带对应验证步骤或测试用例。

## 3. 安全边界与红线
- **严禁**硬编码任何真实 API Key、数据库密码或私钥，统一通过环境变量读取。
- **严禁**未经确认执行破坏性数据库迁移（如 `DROP TABLE`、`TRUNCATE`）或强推主分支（`git push --force`）。
- 如遇到缺失的依赖或权限受阻，直接如实报告原因并停止，禁止绕过安全检查。
